# Paper Bar Logo

Paper Bar is the primary CMC logo mark: five staff lines intersected by a warm vertical paper bar.

## Final Production Files

- `paper-bar-final-transparent-large.png` is the final transparent production logo for application UI and retina displays.
- `paper-bar-final-transparent-small.png` is the final transparent small logo for compact/fallback usage.

## Source And Working Files

- `paper-bar-small.png` is the original small source crop from the application board.
- `paper-bar-large.png` is the regenerated high-resolution opaque source asset.
- `paper-bar-small-transparent.png` is the working transparent small mark.
- `paper-bar-large-transparent.png` is the working transparent large mark currently used by the website.
- `paper-bar-transparent-preview.png` is a transparency preview image, not a production asset.

Use `paper-bar-final-transparent-large.png` for new application UI references unless there is a specific reason to use a source or working file.
